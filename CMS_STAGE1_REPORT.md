# Дополнение первого этапа CMS — 15.11.2026

## Архитектура и предварительный анализ

Существующий проект: React 19, TypeScript, Vite 7, Tailwind 4, React Router, Zod. Поиск Fuse.js с нормализацией ё/е; локальная SVG-карта d3-geo/world-atlas. Существующий Node.js API использует встроенный SQLite; база `.cms/content.sqlite`, первоначальный каталог — `src/data/catalog.json`. Каждая статья хранится отдельно, с опубликованным снимком, редакционным состоянием и номером версии; таблицы history, owner, sessions и attempts уже реализованы. Научные статусы независимы от редакционных. Работает один владелец с scrypt-паролем и серверной cookie-сессией. Публичной регистрации нет. Для этого этапа достаточно развить существующий API; Supabase и внешние ключи не требуются.

Публичного размещения репозиторий и локальная проверка не доказывают. CI запускает проверки, не выполняет деплой. GitHub Pages не может обслуживать этот API; для публичного размещения нужен постоянный Node.js-сервер, диск и HTTPS. Локальная работа проверена, публичное размещение не выполнялось.

## Реализовано в этом изменении

- Общая сессия владельца и панель на публичных страницах; открытие конкретной записи в `/admin?word=…`, создание через `/admin?new=1`, выход.
- Обновление публичного каталога после успешного сохранения. Изменения видны при переходе по SPA без перезагрузки, в других вкладках при фокусе, навигации или перезагрузке. Неподтверждённый сбой обновления не выдаётся за сбой уже состоявшейся записи в БД.
- Предупреждение о несохранённой форме при навигации и закрытии вкладки; индикатор сохранения, блокировка повторного нажатия, сохранение ввода при ошибке API. Форма остаётся в памяти при повторном входе после истечения сессии.
- Редактор разбит на разделы: основная информация, языки, лингвистический анализ и источники. Автоматический редактируемый URL новой записи, серверная проверка уникальности, неизменяемый URL после создания.
- Обзор реальных данных, фильтры категории/языка/статуса и сортировка; перестановка языковых карточек, автоматический код страны, подтверждение удаления.
- Отдельное редакционное примечание для демонстрации без изменения научных фактов. Языковые поля графики, фонетики, семантики и грамматики сохраняются и отображаются в статье и сравнении. Общие замечания аудита показаны отдельно.
- Основной набор: Матрёшка, Калашников, Дача, Интеллигенция, Погром, Самиздат, Спутник, Самовар. Остальные слова, включая балалайку, сохранены в словаре. Два режима сравнения: одно слово и таблица основного набора, с фильтрами языка/темы/достоверности. Архивирование исключает материал из публичных представлений.

Все редакторские изменения записываются в существующую серверную SQLite-БД; localStorage для контента не используется. Предпросмотр до сохранения и несохранённая форма существуют только в памяти вкладки. Браузерные тесты используют отдельную временную БД, не рабочий словарь.

## Проверки

Успешно выполнены: `npm run typecheck`, `npm run lint`, `npm test` (15 тестов), `npm run test:server` (2 теста), `npm run build`, `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium npm run test:e2e` (7 тестов). Браузерные проверки включают отказ неавторизованному API-клиенту, создание/сохранение/публикацию/архивирование/историю, редактирование со страницы слова, сбой API, навигационное предупреждение, отдельную сессию посетителя и перезагрузку. Проверены кириллица, армянские формы, мобильная навигация и отсутствие горизонтального переполнения страницы с таблицей.

При отладке нового теста исправлены ожидание фиксированного числа статей при параллельных сценариях, выбор ссылки-карточки и ожидание завершения диалога отмены перехода. Обработчик предупреждения также защищён от повторного открытия для одного заблокированного перехода. Итоговый полный запуск прошёл.

Остаются предупреждения сборщика об аннотациях в зависимости Zod и размере основного JS-файла (~543 kB до gzip); сборка завершена. Safari, macOS и публичный HTTPS-хостинг в Linux-среде не проверялись.

## Частично и далее

Это дополнение критического первого этапа, а не завершение всего большого ТЗ. Пока нет визуального управления источниками/их верификацией, новыми языками, самим составом и порядком исследования, журналом, страницами, медиа и ручным словом дня. Не реализованы импорт XLSX, расширенные экспорты, отдельные события путешествия и редактор карты. Для дополнительного языка потребуется развитие схемы и справочника. Языковые поля адаптации — текст с атрибуцией; отдельная расширенная модель статусов каждого утверждения и лексикологического типа остаётся следующим этапом. Скрытие отдельной языковой карточки без её удаления пока не предусмотрено; доступны перестановка, подтверждаемое удаление и версии всей статьи.

Нет постоянного push-канала между вкладками. В рабочей БД личный владелец не создавался; автоматические тесты используют временного владельца. Внешние учётные данные не нужны для локального запуска. Секретов и стандартного пароля в исходниках нет.

## Действия автора

Запуск и создание единственного владельца, работа в `/admin`, демонстрация через редакционное примечание, SQLite backup/восстановление и подготовка HTTPS-сервера описаны в ADMIN_GUIDE.md. Кратко: Node.js 24.22+ ветки 24, `npm ci`, `npm run server`; во втором терминале `npm run dev -- --port 5173 --strictPort`. Пароль вводится скрыто на доверенном сервере процедурой из руководства, не в чате или Git. Публичное размещение требует отдельной настройки сервера и домена.
