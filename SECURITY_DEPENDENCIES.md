# Аудит зависимостей второго этапа — 15.11.2026

Команды: `npm audit --json`, `npm audit --omit=dev --json`. Это проверка известных npm advisories по lockfile, не аудит всей безопасности Node.js или приложения.

До изменения: 10 находок в графе зависимостей — 2 critical и 8 moderate. Это число затронутых пакетов, а не независимых уязвимостей.

Vitest обновлён адресно с 3.2.7 до 4.1.12; обновились его согласованные транзитивные зависимости, включая tinypool. `npm audit fix --force` не использовался. Тестовый CLI и API/watch-сервер Vitest в обычном запуске проекта не включены. Известные исходные advisories:

- [GHSA-5gmw-xhrv-c9v3](https://github.com/advisories/GHSA-5gmw-xhrv-c9v3), [GHSA-85c8-ppgw-ccpr](https://github.com/advisories/GHSA-85c8-ppgw-ccpr): prototype pollution → выполнение кода через параметры workers/run в tinypool; относятся к запуску тестового инструментария, а не к Node.js CMS API.
- [GHSA-82fw-gwwq-j7x9](https://github.com/advisories/GHSA-82fw-gwwq-j7x9), [GHSA-qxg6-89mg-rqv8](https://github.com/advisories/GHSA-qxg6-89mg-rqv8): чтение файлов/инъекция кода через mock-инфраструктуру Vitest; открывать тестовый API недоверенным пользователям нельзя. Исправлены обновлением Vitest.

После обновления: **0 critical, 0 high, 7 moderate** в полном npm-графе. Семь умеренных предупреждений относятся к цепочке `typescript-eslint` / `@typescript-eslint/*` / `minimatch`. Это одна транзитивная проблема globparts amplification (DoS) — [GHSA-g3hv-75wg-m249](https://github.com/advisories/GHSA-g3hv-75wg-m249), уязвимый диапазон minimatch `>=7.0.0 <11.0.1`. Принудительная подмена на несовместимый major через overrides не применялась. Нужно дождаться поддерживаемого исправления соответствующей цепочки линтера либо отдельно проверить совместимое обновление; обычный запуск CMS не использует ESLint и minimatch для обработки пользовательских данных.

**`npm audit --omit=dev` сообщил 0 находок** для установленного производственного графа, включая React/Router, Markdown-рендерер и sharp. Node API использует встроенные http/crypto/sqlite, Zod и обработку изображений; тестовые и lint-пакеты не импортируются сервером и не попадают в собранный публичный интерфейс. Vite в режиме разработки — отдельный локальный инструмент, а не production reverse proxy. Не следует считать dev-сервер подходящим для публичного развёртывания.

Markdown не поддерживает raw HTML; ссылки проходят безопасное преобразование react-markdown. Изображения принимаются только после проверки формата/размера/декодирования sharp и перекодирования в WebP; сохраняются в SQLite, не исполняются как файлы. Запись доступна только владельцу с серверной сессией и проверкой Origin. Эти меры не заменяют обновление зависимостей и повторный аудит при их изменении.
