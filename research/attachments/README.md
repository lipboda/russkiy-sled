# Сравнительные таблицы автора

`comparative-tables.xlsx` — побайтная копия приложения «Русский_след_сравнительные_таблицы_без_заливки.xlsx», полученного 15.11.2026. Три листа: американский английский, французский и восточноармянский; на каждом восемь слов в авторском порядке.

Файл сохранён для последующей научной сверки, **не импортирован в каталог или SQLite**. При просмотре найдены реконструкции произношения, учебные примеры, оговорки о статусе нарицательных форм и вероятных путях заимствования. Эти сведения нельзя автоматически превращать в нормативные IPA, корпусные примеры и подтверждённые заимствования. Предыдущее содержание `research/`, каталог и научные статусы не изменены.

Перед импортом требуется процедура из AGENTS.md: чтение восьми оригинальных PDF, сверка источников и обновление IMPORT_AUDIT.md. В этом этапе досье не перечитывались и новый научный аудит не заявляется. Для отдельных полей предусмотрен ручной редактор; автор должен сохранять атрибуцию и оговорки.
