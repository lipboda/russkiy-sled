# Русский след

Исследовательский словарь о переходе русских слов в иностранные языки. React 19, TypeScript, Vite, Tailwind CSS 4. Интерфейс на русском, локальные данные, без сервера и API-ключей.

## Запуск

Нужен Node.js 22.12+ (проверено с Node 24) и npm.

```sh
npm ci
npm run dev
```

Локальный адрес: `http://localhost:5173`. Для проверки production-сборки: `npm run build && npm run preview` (порт 4173). Это локальные серверы, команды не публикуют сайт.

## Что реализовано

- Главная, адаптивное меню, словарь и страницы 58 исследовательских записей: 9 подробных разборов и 49 кратких записей.
- Поиск по русским и иностранным формам, ё/е, опечаткам, подсказки со ссылками и клавиатурным доступом. Фильтры языков (любой/все), темы, статуса, полноты и наличия исследования; сортировка.
- Отдельные раскрывающиеся языковые карточки, происхождение, история, графика, фонетика, семантика, грамматика и вопросы аудита с атрибуцией и страницами PDF.
- Сравнение трёх языков по выбранному слову и параметру. Сводный комментарий аудита явно отделён от данных отдельных языков.
- Локальная SVG-карта мира (177 геометрий стран): масштаб, перетаскивание, выбор страны и боковая панель с языковым фильтром. Клавиатурная альтернатива — список стран и кнопки. Тайлы и внешние сервисы не нужны. Геометрия Natural Earth, public domain, пакет world-atlas; русские названия i18n-iso-countries.
- Исследовательские истории слов, три самостоятельные редакционные методические заметки, страница слова дня, 404.
- Две формы с HTML-валидацией и скачиванием заполненного сообщения в TXT. Ничего не отправляется на сервер; email необязателен.

## Научные ограничения

Это **слой чтения исследовательского аудита**, а не публикация проверенного корпуса. Подробные выводы атрибутированы локальному аудиту; формы, альтернативы, оговорки и расхождения не исправлялись догадками. Внешние оригиналы не проверены заново. Ноль подтверждённых записей — результат текущей верификации, а не утверждение об отсутствии русизмов.

Карты и слово дня используют только `verified`, исключая демонстрационные записи. Поэтому сейчас панель карты честно пуста и слово дня не выбирается. Режим «во всех языках» тоже учитывает только подтверждённые формы. Даты из истории воспроизводятся внутри атрибутированных замечаний аудита; на карте нет недоказанных маршрутов. Редакционные заметки объясняют методику и не выдаются за новые научные исследования.

Исходные PDF и результаты аудита не изменены. `src/data/catalog.json` — компактная производная из `RESEARCH_REGISTRY.json`; `scripts/prepare-catalog.py` воспроизводит этот слой (Python 3, без дополнительных библиотек). Ссылки источников закреплены за коммитом репозитория. Темы — редакционная навигация, не выводы о происхождении. Полное чтение досье и сверка первоисточников остаются необходимыми перед подготовкой production-записей.

## Проверки

```sh
npm run typecheck
npm run lint
npm test
npm run build
npx playwright install chromium
npm run test:e2e
```

В данной облачной машине уже есть системный Chromium; загрузка Playwright с CDN ограничена политикой сети. Здесь браузерные тесты проверены командой:

```sh
PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium npm run test:e2e
```

12 unit-тестов проверяют фильтры, нечёткий поиск и блокировки публикации. 4 браузерных сценария проверяют поиск, статьи, фильтры, сравнение, карту, редакционные маршруты, скачивание форм, 404 и мобильную навигацию. CI повторяет проверки для PR. Наличие этой конфигурации не означает, что удалённый CI уже выполнен.

## Структура и добавление данных

- `src/domain/` — Zod-схемы, проверка sourceIds, правила допуска, поиск и тесты.
- `src/data/` — исследовательский каталог и редакционный журнал.
- `src/components/` — общие компоненты; `src/pages/` — страницы; `src/styles.css` — адаптивное оформление.
- `tests/` — браузерные сценарии; `research/` — неизменённые материалы.

Новое слово должно иметь уникальные id/slug, русский заголовок, темы, независимые `articleDepth` и `publicationStatus`, языковые карточки с `attestationStatus`. Для каждого сообщения указывайте источник и локатор. Отсутствующие поля оставляйте пустыми. Проверенные формы требуют источника с `verifiedAt`; демонстрационные статьи не могут быть опубликованы как verified. Автоматическое повышение статусов запрещено. После редакторской проверки добавляйте записи через схемы в `src/domain/catalog.ts` и выполняйте проверки. Текущие статусы — `draft` или `provisional`.

Backend, модерация, отправка форм, пользовательские аккаунты и публичный деплой в эту версию не входят. Список следующих задач — в PLAN.md.

## Серверная CMS (первый этап)

Для текущей ветки нужны Node.js 24.22+ и запущенный API: `npm run server`, затем в другом терминале `npm run dev`. Панель — `/admin`; безопасное создание единственного владельца, работа с записями, резервные копии и ограничения описаны в [ADMIN_GUIDE.md](ADMIN_GUIDE.md). Существующие данные мигрируют в SQLite при первом запуске. Журнал, главная и медиатека пока остаются за границами этого этапа.
