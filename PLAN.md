# План разработки

## Готово и проверено локально

- [x] React / TypeScript / Vite / Tailwind в корне существующего репозитория.
- [x] Издательская визуальная система, адаптивная навигация, focus, reduced motion.
- [x] Модель и валидация источников, отдельные статусы публикации и аттестации.
- [x] Исследовательский слой: 58 записей, 9 подробных разборов, без повышения статусов аудита.
- [x] Главная, поиск, подсказки, фильтры, сортировка, статьи, сравнение.
- [x] Интерактивная локальная карта, масштабирование, перемещение, выбор страны, панель.
- [x] Путешествия слов с оговорками; методический журнал; корректное состояние слова дня.
- [x] Формы предложения слова / ошибки со скачиванием, без имитации отправки.
- [x] TypeScript, ESLint, 12 unit-тестов, 4 браузерных сценария, production-сборка.
- [x] CI-конфигурация и документация.

## Требует следующего этапа

- [ ] Редакторская проверка конкретных первоисточников и утверждений, снятие publication gates по одному, а не пакетно.
- [ ] Production-данные и независимые языковые наблюдения со статусом каждого поля; заполнение карты и слова дня только после верификации.
- [ ] Более подробные маршруты и датировки после проверки первичных исторических текстов.
- [ ] Расширенная проверка доступности со скринридером и на реальных мобильных устройствах.
- [ ] Серверные формы, модерация, антиспам — отдельное согласование инфраструктуры.
- [ ] Публичная публикация — только по разрешению владельца.

GitHub API в текущей среде запрещён сетевой политикой. Доступ к api.github.com добавлен в черновик настроек; для автоматического создания PR нужно применить это изменение. Слияние в main не выполняется.
