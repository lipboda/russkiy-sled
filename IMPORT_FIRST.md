# IMPORT FIRST — до разработки и импорта данных

Этот комплект содержит техническое задание и фактические исследовательские материалы проекта.

1. Прочитай `AGENTS.md`, `PROJECT_SPEC.md`, `research/README_FOR_CODEX.md` и
   `research/UPLOADED_DOSSIERS_MANIFEST.md`.
2. Сначала составь инвентаризацию научной базы. Обязательно изучи все восемь досье из
   `research/UPLOADED_DOSSIERS_MANIFEST.md`, включая оригинальные PDF и текстовые копии.
3. Сохраняй исходные отчёты, PDF и рабочие книги под `research/` без изменений.
4. До создания production-записей словаря создай `research/IMPORT_AUDIT.md`: каждое слово,
   подтверждённые и неподтверждённые формы по целевым языкам, значения, тип употребления,
   точные источники/URL, статус доказательства, ограничения доступа, конфликты и нерешённые вопросы.
5. Не считай число отчётов, слов или найденных упоминаний количеством подтверждённых заимствований.
6. Реестр из 50 кандидатов — только список для проверки. Не отмечай его записи как подтверждённые
   без проверки лежащих в основе свидетельств.
7. Две версии отчёта «Балалайка» сохраняй раздельно до проверки расхождений.
8. Не используй синтетические ответы анкет или вымышленные профили респондентов как научные данные.
9. Только после аудита создавай нормализованные данные приложения отдельно от исходных файлов.
   Пропуски и неопределённость должны быть видны в интерфейсе.
