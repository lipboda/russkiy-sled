# Финальная публикация и демонстрация

Ветка `feat/homepage-editorial-redesign`, продолжение `a4b61fb`. На MacBook уже есть согласованно импортированные 28 черновиков. Повторять импорт не нужно. Команда ниже не создаёт базу и не заменяет её облачной копией. Разрешение владельца на публикацию всего финального набора дано в текущем задании; дополнительных подтверждений по статьям команда не требует.

## Обновление и публикация на MacBook

1. Сохраните свои изменения кода. В GitHub Desktop: **Fetch origin → feat/homepage-editorial-redesign → Pull origin**. Через **Repository → Open in Terminal** откройте корень проекта.
2. Остановите API и Vite сочетанием Control+C в обоих терминалах. Закройте редактирование CMS до завершения публикации. Сохраните уже сделанные резервные копии.
3. Выполните:

   ```sh
   npm ci
   npm run build
   npm run content:publish-final
   ```

   Нужен прежний Node.js 24.22+ в ветке 24 и npm из его комплекта. По умолчанию используется `.cms/content.sqlite`. Если раньше задавали `CMS_DB_PATH`, используйте тот же путь и для публикации, и для запуска API.

   Команда читает сохранённые `import-entry`-сопоставления именно финального пакета, проверяет все 28 существующих записей, определения, ударения, происхождение, источники, языковые формы, научные выводы и дубликаты. Она не читает старый незавершённый JSON и не выполняет импорт. Перед записью создаётся консистентная SQLite-копия с WAL в `.cms/backups/before-final-publication-….sqlite` (при нестандартной базе — `backups` рядом с ней), права 0600. Путь печатается в терминале. Если копирование или проверка не удались, публикация не начинается. Изменения базы после предварительной проверки останавливают операцию.

   Все 28 публикуются штатным `save` CMS в одной транзакции. При ошибке откатывается весь пакет. Сохраняются ID, URL, источники, обложки, связанные слова, история, владелец, пароль, настройки, медиа, журнал и «Слово дня». Видимость карточек финального набора включается согласно заданию; научные `attestationStatus`, `publicationStatus`, `scientificStatus`, типы соответствий и даты проверки источников автоматически не повышаются.

   Ожидаемый отчёт:

   ```text
   publishedFinal: 28
   main: 8
   additional: 20
   researchCards: 24
   changed: 28
   conflicts: 0
   scientificStatusesChanged: false
   ```

   Если часть уже опубликована без новых правок, `changed` меньше, а `skipped` больше. Повторный запуск для того же актуального содержимого: `changed: 0`, `skipped: 28`, без лишних редакций. После последующей правки команда опубликует только изменённые записи финального набора.

4. Запустите API:

   ```sh
   npm run server
   ```

   Во втором терминале в том же каталоге:

   ```sh
   npm run dev -- --port 5173 --strictPort
   ```

5. В Safari откройте сайт `http://localhost:5173/`, панель владельца — `http://localhost:5173/admin`. Пароль прежний. Если вкладка была открыта до обновления, перезагрузите её Command+R.

## Проверка перед выступлением

- На главной есть число опубликованных статей, представленных языков и опорных стран, поиск, карточки, карта, исследование, «Слово дня» и журнал. Показатели рассчитаны по публичному каталогу. Для чистого финального набора: 28 слов, 9 языков, 9 опорных стран, 8 исследовательских слов.
- В словаре найдите по очереди основные и дополнительные слова. Все 28 доступны; у кратких статей допустим один язык. У перестройки доступны семь форм, у балалайки — пять. Открывайте статьи через каталог: сохранённые старые URL могут отличаться от slug финального JSON.
- У матрёшки и остальных семи основных слов есть американская английская, французская и восточноармянская карточки, четыре направления адаптации, пять критериев освоенности, заключение и источники. Научные пояснения о переводах, собственных именах, опосредованных путях и ограничениях произношения сохранены.
- Исследование по умолчанию сохраняет последовательность: матрёшка → калашников → дача → интеллигенция → погром → самиздат → спутник → самовар. Режим «Общий словарь» включает все опубликованные словарные статьи и их формы. Существующий нестандартный URL не исключает слово из основной выборки.
- В карте исходно виден мир без надписей. Выберите страну мышью или клавиатурой через список: появятся её флаг, языки и ссылки на статьи. Закройте панель, проверьте масштаб и кнопку сброса. На мобильном панель открывается под картой.
- Слой **«Словарные соответствия»** показывает опубликованные формы с источниками и опорной страной. Он включает также имена, переводы и другие сопоставления, не заявляя их подтверждёнными заимствованиями. Слой **«Подтверждённые заимствования»** требует `correspondenceType=borrowed`, `attestationStatus=verified` и проверенные источники; на тестовом финальном наборе он пуст, поскольку публикация не подменяет научную проверку.
- Флаги — локальные SVG flag-icons (MIT), единый размер и подпись языка рядом; emoji и внешняя сеть для них не нужны. Флаг обозначает опорную страну / вариант, а не исключительную территорию языка.
- Если редакционных выпусков «Слова дня» нет, сайт выбирает слово из опубликованного содержательного словаря детерминированно на сутки. Это витрина существующей статьи, не новая редакционная публикация; журнал и выпуски в базе не создаются и не перезаписываются.
- Для демонстрации обычного посетителя выйдите из административной панели. У владельца инструменты редактирования остаются доступными; в админке научные статусы сохранены. Публичная часть не выводит редакционные плашки и машинные комментарии импорта; исходный материал и ограничения не удалены из SQLite.

## Что произошло со старыми заготовками

После полной финальной публикации публичный каталог не показывает демонстрационные записи и нетронутые короткие стартовые заготовки без определения, побайтно совпадающие с исходным seed. Сами строки SQLite, их история и черновики не удаляются. Любые пользовательские правки и содержательные сторонние публикации сохраняются. Поэтому вся база в тесте содержит 66 записей, а публичный словарь — 28. Если у владельца есть другие содержательные опубликованные статьи, публичное общее число может быть больше 28; именно финальных статей команда проверяет всегда 28. Чужие черновики команда не публикует.

## Фактически проверенный результат

Только на отдельных временных базах: 28 опубликованных статей, 8 подробных / 20 компактных, 24 исследовательские карточки, 40 дополнительных форм, 9 языков, 0 конфликтов. Повтор: ноль изменений, ноль дополнительных строк истории. Целостность рабочей SQLite и резервной копии — `ok`; научные статусы и пользовательские таблицы сохранены. Отчёт: `research/imports/FINAL_PUBLICATION_TEST_REPORT.json`.

В отдельном слое получилось 64 словарных соответствия, включая четыре армянские формы, которые исходный составитель исключил из потенциальных заимствований; они не считаются доказанными русизмами. Число 60 из файла нигде не подставляется как статистика подтверждения. Доказанных заимствований в проверенном наборе автоматически не добавилось.

Пройдены TypeScript, ESLint, 20 модульных и 31 серверный тест, production-сборка; браузерные сценарии проверяют существующую CMS и весь финальный публичный набор. `npm run test:e2e` запускает 16 прежних сценариев; финальный сценарий отдельно — `npm run test:e2e:final` (Linux: добавьте `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium`; на Mac после установки Chromium этот override не нужен). Тестовый runner создаёт и удаляет только временную базу, пользовательскую SQLite не использует.

Финальный браузерный сценарий открывает все 28 статей, проверяет 8×3, все языковые вкладки дополнительных статей, источники, отсутствие редакционных предупреждений / технических ID, загрузку SVG, поиск, общую таблицу, оба слоя карты, переходы и отсутствие горизонтальной прокрутки на ширинах 1440, 1280, 1024, 768 и 390. Скриншоты создаются в `test-results/final-demo/`; это реальные страницы опубликованного тестового словаря. Настоящий Safari в Linux недоступен. Предупреждения сборки о размере JS и аннотациях Zod прежние.

**Локальная база MacBook недоступна из облака. Публикация на вашем компьютере ещё не выполнялась; её выполняет одна команда выше. Облачная пользовательская база в этой задаче не заменялась, повторный импорт в неё не запускался.**
