# Главная страница: обновление

Ветка `feat/homepage-editorial-redesign` основана на `feat/atlas-map` и сохраняет этап 3 CMS и обновлённую карту. База и API не изменялись, миграция не требуется.

В GitHub Desktop сохраните свои изменения кода, остановите API/Vite Control+C, сделайте привычную резервную копию SQLite командой db:backup с новым именем, нажмите Fetch origin и выберите новую ветку. В корне проекта выполните `npm ci`, `npm run build`, затем `npm run server`; во втором терминале — `npm run dev -- --port 5173 --strictPort`. Safari: http://localhost:5173/, панель владельца: http://localhost:5173/admin. Владелец и пароль остаются прежними. Для отката достаточно переключить код на предыдущую ветку и переустановить зависимости; структура базы не менялась.

Изменены Home.tsx, стили главной, placeholder общего SearchBox, загрузка публичных данных (catalog.ts/main.tsx), preview-режим прежней WorldMap и браузерные тесты. Отдельного каталога, картографического слоя данных, административного API или новой системы рекомендаций не создавалось. Карточки выбираются детерминированно по русскому алфавиту. Публикации и показатели читаются только из публичных снимков CMS; число языков/стран учитывает подтверждённые недемонстрационные формы. Ноль подтверждённых связей честно отображается как ноль, а не как план наполнения.

Словарь и публикации загружаются независимо: отказ одного API не скрывает статические сведения и другой доступный раздел. При первой загрузке исходный bundled seed не служит подменой недоступного публичного каталога. Одновременные запросы обновления объединяются. Обновление открытой вкладки происходит при навигации, фокусе и действиях CMS; постоянного push-канала нет.

Проверки: TypeScript, ESLint, 16 unit-тестов, 9 серверных тестов, сборка; 15 браузерных тестов включают существующие CMS-сценарии и новые сценарии главной. Размеры: 1440×900, 1280×800, 1024×768, 768×1024, 390×844. Скриншот MacBook — эмуляция размера Chromium, не проверка настоящего Safari. Предупреждения Vite о размере JS и аннотациях Zod остаются. CSS и изображения используют существующие возможности проекта; дополнительных шрифтов и зависимостей не добавлено.

Не реализовывались импорт запланированных 28 статей, редактор статических текстов главной и публичное размещение. Методология, выборка, PDF и пользовательские записи не менялись. Начальная частичная ошибка API не равнозначна пустому словарю. Настоящий Safari и пользовательская база MacBook здесь недоступны.

Пример резервной копии из корня проекта (имя должно быть новым):

```sh
npm run db:backup -- "$HOME/Desktop/russkiy-sled-before-homepage-$(date +%Y%m%d-%H%M%S).sqlite"
```

Сохраните копию отдельно от репозитория; не коммитьте SQLite и `.env`.
